# Playmake service announcements

Public, plain-text notices read by the Playmake iOS app independently of its API and authentication. No app source, secrets, or user data belong here.

- `production.json`: regular Playmake
- `dev.json`: Playmake Test and preview apps

Use `npm run notice` from the private Playmake repository to validate, publish, schedule, or clear notices. See its `docs/service-announcements.md`. Notice content and history are public. An empty feed is normal and means there is no active service announcement.
